## BUILT-IN FUNCTIONS AND LAMBDA FUNCTIONS - RELATING TWO NUMBERS

---

### AIM  
To write a Python program to  calculate the value of the following expression by using lambda function. The expression is -
(x / 10) * (y / 2) * z — using a lambda function.

---

### ALGORITHM

1. Start
2. Input values for x, y, and z from the user.
3. Define a lambda function as:
      - expr = lambda x, y, z: (x / 10) * (y / 2) * z
4. Call the lambda function with x, y, and z and store the result.
5. Print the result.
6. End

### PROGRAM

```
# Reg.No-212223050048
# Name-SIBIRAJI M
# Write your code here
a=int(input())
b=int(input())
c=int(input())
r=lambda x,y,z:(x / 10) * (y / 2) * z
print(r(a,b,c))
```
